# Fizyo Seans

Fizyoterapi tedavi programı ve seans yönetimi uygulaması: hastalık protokolleri, yöntemler, egzersizler, ölçekler, özel klinik testler, ICF hedefleri, canlı seans ve hasta çıktısı.

- Tek dosyalık uygulama: `index.html`
- Hasta verileri yalnızca kullanılan tarayıcıda saklanır (localStorage); bu depoya veya herhangi bir sunucuya gönderilmez.
- Bu sürümde "Claude'a sor" özelliği soruyu panoya kopyalayıp claude.ai'yi açar.
